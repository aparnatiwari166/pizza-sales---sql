📌 Project Overview

This project focuses on analyzing pizza sales data using SQL to identify business trends, understand customer ordering patterns, and generate meaningful insights.

The objective is to explore sales performance, popular pizza categories, customer preferences, and revenue trends using SQL queries.

🎯 Project Objectives

- Analyze total revenue and overall sales performance.
- Identify the most popular and least popular pizzas.
- Understand daily and hourly ordering trends.
- Analyze sales by pizza category and size.
- Identify top-performing pizzas based on revenue and quantity sold.
- Generate actionable business insights from the data.

📂 Dataset Description

The project uses four datasets:

Dataset| Description
"pizzas"| Contains pizza IDs, sizes, and prices.
"pizza_types"| Contains pizza names, categories, and ingredients.
"orders"| Contains order IDs and order dates and times.
"order_details"| Contains order details, pizza IDs, and quantities ordered.

🛠️ Tools & Technologies

- SQL

- Relational Database Management
- Data Analysis

🔍 SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT, AVG)
- Joins (INNER JOIN)
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date and Time Functions

💡 Key Insights

The analysis aims to identify:

- Overall revenue and sales performance.
- Customer ordering patterns throughout the day.
- Best-selling pizza categories and sizes.
- Top and low-performing pizza products.
- Revenue contribution across different pizza categories.
